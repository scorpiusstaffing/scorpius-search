How to install in Gmail

  1. Click ONCE on the signature you want above (anywhere inside the box).
  2. Press Cmd + A to select the entire signature (only the copy-zone is selectable), then Cmd + C.
  3. Open Gmail → ⚙️ → See all settings → General tab → scroll to Signature.
  4. Click + Create new if you don't have a signature yet, or click into an existing one.
  5. Paste with Cmd + V. The logo, fonts, colors and links all carry over.
  6. Under Signature defaults, set "For new emails use" and "On reply/forward use" to this signature for jonathandeklerk@scorpiussearch.com.
  7. Scroll to the bottom and click Save changes.
